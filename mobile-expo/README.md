# Mobile Expo App

Expo SDK 57 기반 Android·iOS·웹 공통 도시 편집기입니다.

## 실행

```powershell
npm install
npm run web
```

Android 네이티브 에뮬레이터:

```powershell
npx expo run:android
```

## 포함 기능

- 23개 도시 에셋 선택 및 배치
- 터치·마우스 드래그 이동
- 좌우 반전만 허용
- 복제, 삭제, 앞·뒤 레이어
- 16px 스냅, 격자 표시
- 참고 도시 이미지 토글
- AsyncStorage 저장·불러오기
- 반응형 에셋 팔레트
